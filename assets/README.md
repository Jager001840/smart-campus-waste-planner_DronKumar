# Assets Directory

## Project Asset Architecture
* **Project Title:** Smart Campus Waste Monitoring & Collection Route Planner
* **Developer:** Dron Kumar Singh
* **Integration:** COA, FLAT, DAA

### Zero External Asset Dependencies
In compliance with the project's **Mandatory Technology Stack** constraints:
- **No external icon font libraries:** No FontAwesome, Google Material Icons, or third-party web font kits are imported.
- **Universal Unicode Standard:** User interface iconography uses native UTF-8 Unicode glyphs (e.g., ♻️, 📊, 🗑️, 🔢, ⚙️, 🗺️, ℹ️, ➕, 📝, 🚀, 🔄, ⚠️, 📦, 🚨, ✅, 🔍, ⚡, 🧹, 🧪).
- **Scalable Vector Graphics (SVG):** Both the FLAT DFA state diagram and the DAA campus navigation topology map are rendered dynamically via standard inline HTML5 `<svg>` elements.
- **100% Offline Portability:** The application runs completely isolated from external CDNs, requiring zero internet connectivity after project files are in place.
